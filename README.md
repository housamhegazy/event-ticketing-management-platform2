# 🎟️ Eventify - Full-Stack Event Booking Platform

**Eventify** is a professional MERN stack application designed to simplify the process of discovering, booking, and managing events. Whether you are an event organizer or a guest, Eventify provides a seamless and secure experience.

---

## 🚀 Key Features

### 👤 For Users:
- **Smart Discovery:** Browse and filter events by category or date.
- **Secure Booking:** Book tickets for events with real-time seat/spot availability.
- **Profile Management:** View your booked events and manage personal info.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop.

### 🛠️ For Admins (Dashboard):
- **Event Management:** Full CRUD (Create, Read, Update, Delete) operations for events.
- **Media Uploads:** Integrated with Cloudinary for fast and optimized image hosting.
- **Analytics:** Track the number of bookings and user engagement.

---

## 🛠️ Tech Stack

**Frontend:**
- **React.js** (Functional Components, Hooks)
- **Redux Toolkit & RTK Query** (State Management & API Fetching)
- **Material UI (MUI) & Bootstrap** (UI Components & Styling)

**Backend:**
- **Node.js & Express.js** (Server-side Logic)
- **MongoDB & Mongoose** (NoSQL Database)
- **JWT & Cookies** (Secure Authentication)
- **Cloudinary** (Image Management)
